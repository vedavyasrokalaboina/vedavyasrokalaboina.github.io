Final-Year Project · Team of 3

Thrust Vector Control Using Jet Vanes

Jun 2023 – Apr 2024 Mach 1.8 6 nozzle geometries CATIA V5 · ANSYS ICEM CFD/CFX
Overview

This project investigated how nozzle exit geometry affects supersonic exhaust flow for thrust vector control (TVC) using jet vanes — a technique that steers a vehicle by deflecting the exhaust jet directly, rather than relying on aerodynamic control surfaces like rudders or elevators. That makes it especially valuable in high-speed or high-altitude flight regimes where conventional control surfaces lose effectiveness.

As a team of three, we sized a converging-diverging nozzle from isentropic flow relations and modelled six distinct exit geometries — circular, square, rectangular, triangular, hexagonal, and elliptical — with jet vanes integrated at the exit plane, all designed for the same exit Mach number of 1.8.

Methodology

Each geometry was meshed in ANSYS ICEM CFD and simulated in ANSYS CFX using the k-omega SST turbulence model, with matched boundary conditions (12 atm / 288 K inlet, 1 atm / 288 K ambient) across all six variants — so the comparison came from geometry alone, not inconsistent setup.

The key metric was supersonic core length — the distance downstream of the nozzle exit over which the jet's velocity stays nearly constant before atmospheric mixing and turbulence cause it to decay. A longer, more stable core generally means more coherent, controllable thrust vectoring.

Results

Comparing core length across all six geometries against the circular baseline, the square exit produced the longest core overall, while the rectangular exit's performance sat closest to the circular baseline — making it the strongest non-circular candidate where circular-like behaviour is the design target.
